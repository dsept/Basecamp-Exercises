Factory Inventory Management — Architecture

Day 1 · Inventory Management workshop · single-page reference
Vue 3 · FastAPI · in-memory mock data

A full-stack demo for a Claude Code workshop. The frontend is a Vue 3 single-page app served by Vite on port 3000; the backend is a FastAPI service on port 8001 that loads JSON fixtures into memory at startup and serves them through a small set of read-only REST endpoints.

02System architecture

03Frontend & backend at a glance

Frontend · client/

  • App.vue — root layout, top nav, filter bar, router-view
  • Router — createWebHistory() in main.js
  • Views — Dashboard, Inventory, Orders, Demand, Spending, Reports (Backlog component exists)
  • State — local ref() + computed(); no Vuex/Pinia
  • Composables — useFilters(), useAuth(), useI18n() (en / ja)
  • HTTP — axios in src/api.js, base URL http://localhost:8001/api

Backend · server/

  • main.py — FastAPI app, all routes, CORS middleware
  • mock_data.py — loads JSON fixtures on import
  • models.py — Pydantic schemas for response validation
  • Filter helpers — apply_filters() (warehouse/category/status, case-insensitive, skips on "all"), filter_by_month() (month or quarter)
  • Backlog enrichment — adds has_purchase_order from purchase_orders.json
  • Run — uv run python main.py · port 8001

06Data flow — loading the dashboard

  1. User navigates to /
    Vue Router resolves to views/Dashboard.vue; onMounted kicks off loadData().
  2. Filters are read from the shared composable
    useFilters().getCurrentFilters() returns { warehouse, category, status, month } from the top filter bar.
  3. Four parallel API calls via axios
    Promise.all issues getDashboardSummary, getOrders, getInventory, getBacklog against http://localhost:8001/api.
  4. FastAPI handlers run
    Each route applies apply_filters() (warehouse/category/status, "all" skips), filter_by_month() for orders, then aggregates totals for the summary endpoint.
  5. Data comes from in-memory fixtures
    mock_data.py loaded the JSON files in server/data/ when the module was first imported — no DB hit.
  6. Pydantic validates the response, axios resolves
    JSON arrives back in the browser; reactive ref()s update; computed() properties recalc; charts (donut, bar, line) and tables re-render.

07Running locally

One command: ./scripts/start.sh from the project root — installs deps if missing, starts both servers in the background, writes logs to /tmp/inventory-*.log.

Manual: cd server && uv venv && uv sync && uv run python main.py for the API; cd client && npm install && npm run dev for the SPA.

Tests: uv run pytest tests/backend/ -v — uses FastAPI's TestClient against the same in-memory fixtures.
